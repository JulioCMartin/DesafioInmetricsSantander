# Desafio F1RST - QA Cypress 🚀

## Tecnologias Utilizadas:

- Cypress 14.x (ou superior)
- JavaScript
- Cucumber (BDD)
- Cypress Cucumber Preprocessor

---

## ✅ Pré-requisitos:

- Node.js (recomendo versão 18.x ou superior)
- npm (ou yarn)
